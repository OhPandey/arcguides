# ARC Guides

A community-driven **open fanpage for the game _Avatar Legends: Realms Collide_**.

This project aims to collect and present useful information about the game in one place.

The website is built with **Next.js**, **React**, and **TailwindCSS**, and is deployed using **GitHub Pages**.

**Everyone is welcome to contribute**.

---

## Contributing

You can help by:

- Providing **evidence or proof** of game mechanics (screenshots, recordings, etc.)
- Improving existing content
- Fixing mistakes
- Improving UI or functionality
- Reporting issues

Contributions can be made in two ways:

### 1. Submit information directly

You can message **iPandey on Discord** with screenshots or other evidence of game mechanics, events, or gameplay details, and it can be added to the project.

### 2. Contribute via GitHub

1. Fork the repository  
2. Create a new branch  
3. Make your changes  
4. Open a Pull Request  

Please try to keep contributions **clear, factual, and well structured**.
